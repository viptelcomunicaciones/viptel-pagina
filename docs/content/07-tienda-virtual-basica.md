# Viptel Web - Tienda Virtual Basica

## Descripcion General

La Tienda Virtual Basica de VIPTEL WEB es una solucion de comercio electronico desarrollada con **FRAMEWORKS MODERNOS** y buenas practicas de arquitectura (**CLEAN CODE**, **PRINCIPIOS SOLID**), orientada a negocios que quieren empezar a vender en linea de forma rapida, segura y escalable. Esta pensada como una base e-commerce autosostenible y rentable.

---

## Principales Funcionalidades

### Arquitectura e-commerce sobre frameworks modernos

- Implementacion sobre plataformas y frameworks actuales seleccionados segun los requerimientos del proyecto.
- Diseno modular siguiendo **PRINCIPIOS SOLID**: modulos separados para catalogo, carrito, checkout, pagos y usuarios.
- Codigo estructurado y limpio.

### Gestion de catalogo de productos

- Creacion y edicion de productos con campos estandar: nombre, descripcion, precio, imagenes, SKU, categoria, estado.
- Organizacion por categorias y subcategorias.
- Control basico de stock y visibilidad de productos agotados.

### Carrito de compras y proceso de checkout

- Carrito persistente.
- Flujo de checkout simplificado.
- Validaciones de datos y calculo basico de costos adicionales.

### Integracion con pasarelas de pago locales

- Integracion con pasarelas de pago utilizadas en Colombia (PayU, ePayco, Wompi, PSE, tarjeta de credito).
- Manejo de estados de pago y callback/confirmacion.
- Configuracion de moneda, impuestos y parametros de cobro.

### Gestion de pedidos y clientes

- Panel de administracion para visualizar pedidos y estados.
- Registro de datos del cliente asociado a los pedidos.
- Exportacion basica a CSV/Excel.

### Diseno responsive y experiencia de usuario

- Interfaz adaptada a dispositivos moviles.
- Componentes de interfaz reutilizables.

### Seguridad, rendimiento y mantenimiento

- HTTPS (SSL) para proteger datos y procesos de pago.
- Configuracion de cache y optimizacion de recursos.
- Base preparada para actualizaciones y parches de seguridad.
